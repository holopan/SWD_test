## Response Section

**Database Indexing** คือ การนำข้อมูลมาจัดทำสารบัญและเมื่อมีการค้นหาข้อมูลที่บันทึกไว้ในสารบัญซึ่งจะทำให้ DB ไปถึง Address ของข้อมูลได้เร็วขึ้น

### ข้อดีของการทำ Database Indexing
สามารถหาข้อมูลได้เร็วขึ้นอย่างมากและลดการใช้ memory จากการ query ข้อมูลปริมาณมากเพราะได้มีการทำสารบัญของข้อมูลไว้แล้วและยังช่วยในเรื่องของการเรียงลำดับข้อมูลและการ join ให้เร็วขึ้นได้

### ข้อจำกัดของการทำ Database Indexing
พื้นที่ในการจัดเก็บที่มากขึ้นจากการทำสารบัญข้อมูลและในบางครั้งถ้าเรา query ไม่โดน index การ query ก็จะยังคงช้าอยู่แต่เรายังคงใช้พื้นที่ในการจัดเก็บสารบัญอยู่และยังทำให้การเขียนข้อมูลช้าลงด้วย
